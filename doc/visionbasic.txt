1. Filetype detection                                  *visionbasic-detection*

Vision BASIC sources normally use the .bas extension, which is also claimed by
Visual Basic, QBasic, FreeBASIC, CBM BASIC and others — and both Vim and
Neovim ship a guess of their own for it. So a .bas file is only claimed when
its first 100 lines contain a keyword that exists in Vision BASIC and
essentially nowhere else (MOBXY, BMPCLR, HALTINT, REUPEEK, ASSEM and the
like). The .vb64 and .vbas extensions are claimed outright.

A filetype you chose yourself — in a modeline or by hand — is never overruled;
only Vim's own generic BASIC guesses are.

                                                *g:visionbasic_claim_bas*
To take over every .bas file regardless of content: >

    let g:visionbasic_claim_bas = 1
<
To leave .bas files entirely alone: >

    let g:visionbasic_claim_bas = 0
<
Either way you can always set the filetype by hand: >

    :setfiletype visionbasic
<
or with a modeline in the listing itself: >

    10 REM vim: set filetype=visionbasic :
<

2. Commands                                             *visionbasic-commands*

:VBDoc [{keyword}]                                                    *:VBDoc*
    Show the reference entry for {keyword}, or for the word under the cursor,
    in a preview window. Completes on every Vision BASIC keyword and 6502
    mnemonic.

:VBCommentMode                                                *:VBCommentMode*
    Toggle 'commentstring' between REM (BASIC mode) and ; (machine language
    mode). Vision BASIC uses both, and 'commentstring' can only hold one.

:VBNumber [{start}] [{step}]                                       *:VBNumber*
    Add line numbers to the unnumbered lines in the range, starting at {start}
    (default 10) and counting up by {step} (default 10). Lines that already
    carry a number are left alone. Defaults to the whole file.

:VBRenumber [{start}] [{step}]                                   *:VBRenumber*
    Renumber every numbered line in the buffer and follow the references:
    GOTO, GOSUB, THEN and ELSE targets, the line numbers of DESC, TRAP and DO,
    the second argument of INTERRUPT (the first is a raster line, not a line
    number) and the target of POINT. Text inside REM and ; comments is left
    untouched.

:VBUppercase                                                    *:VBUppercase*
    Fold the Vision BASIC keywords and 6502 mnemonics in the range up to upper
    case, leaving string literals, comments and your own variable names alone.
    Defaults to the whole file.

3. Mappings                                             *visionbasic-mappings*

K                       Show the reference entry for the keyword under the
                        cursor (see |:VBDoc|). Only mapped if you have not
                        already mapped K yourself.

<LocalLeader>c          Toggle BASIC/ML comment mode (see |:VBCommentMode|).

<LocalLeader>u          Upper-case the keywords in the buffer (|:VBUppercase|).

With 'matchit' loaded, % jumps between FOR/NEXT, PROC/RETURN, STARTINT/INTEND,
LOCAL/GLOBAL, ASSEM/BASIC and MODULE/MODULE END.

4. Options                                               *visionbasic-options*

                                          *g:visionbasic_auto_uppercase*
Vision BASIC listings are traditionally upper case. By default, leaving insert
mode folds the keywords on the current line up to upper case — type in lower
case, get a proper listing. Strings, comments and your own identifiers are
left as typed. To turn this off: >

    let g:visionbasic_auto_uppercase = 0
<
|:VBUppercase| still works when the automatic pass is disabled.

                                          *visionbasic-statusline*
The current comment mode is available for a statusline: >

    set statusline+=%{visionbasic#mode()}
<

5. Completion                                         *visionbasic-completion*

'omnifunc' is set to visionbasic#complete, so CTRL-X CTRL-O completes Vision
BASIC keywords, with the syntax line in the popup menu and the full reference
entry in the preview window. Inside a [...] machine language block it
completes 6502 mnemonics instead.

Keywords Vision BASIC does not implement — the BASIC V2 leftovers USR, FRE,
POS, SQR, LOG, EXP, COS, SIN, TAN and ATN — are marked "x" in the menu.

7. Language quirks                                        *visionbasic-quirks*

Parentheses are NOT allowed in math expressions and there is no operator
precedence: expressions evaluate strictly left to right. 4+3*5-2*6 is
(((4+3)*5)-2)*6 = 198.

Variable names start with a letter, are significant to 8 characters, and may
contain !@#%&? and digits. A name may contain a keyword but may not start with
one. String variables end in $. Variables are integers unless declared
DECIMAL.

Machine language is entered with ASSEM and left with BASIC. Mnemonics are
wrapped in [] brackets, statements inside them are separated by ":", and ";"
starts a comment. Branches and jumps may target a BASIC line number directly,
e.g. JMP1000.

These commands stay usable inside an ASSEM block:

  START, GOTO, GOSUB, RETURN, REM, TAG, PROC, MODULE
  LOCAL, GLOBAL, ADD, SUBTRACT, COMPARE, HALF, DOUBLE, VARIABLES
  HALT, RESUME, VERSION, DEBUG, STARTINT, RASTER, BYTES, STRINGS

VOICE must be called before FREQ, PULSE, ADSR and WAVE — they all act on the
current voice.

Always HALTINT before your program exits, or the machine is left running your
raster interrupt.

Strings and string variables cannot be returned from subroutines.

8. Keyword reference                                    *visionbasic-keywords*

Every entry is also reachable from the buffer with K or |:VBDoc|.


------------------------------------------------------------------------------
ASSEMBLER MODE
------------------------------------------------------------------------------

ASSEM                                                      *visionbasic-ASSEM*
    Switches into assembler mode. Following lines are assembled as 6502
    machine language until BASIC switches back.

    Example: ASSEM

    In ML mode, mnemonics are enclosed in [] brackets and a semicolon (;)
    starts a comment, e.g. 100 [LDA1: ORA #1: STA1] ; TURN BASIC ROM ON.
    Branches and jumps take a line number directly, e.g. JMP1000.

    Note: In ML mode mnemonics are wrapped in `[]` and `;` starts a comment.
    Branches and jumps may target a BASIC line number directly, e.g.
    `JMP1000`.

BASIC                                                      *visionbasic-BASIC*
    Switches out of assembler mode and back into BASIC.

    Example: BASIC

LABEL label [= vov]                                        *visionbasic-LABEL*
    Identical to TAG. Creates a label that can be used in place of a value or
    address.

    Example: LABEL SCREEN = 1024

    Tags and variables can be used in place of values and addresses in ML
    mode. Commands that are ML-safe: START, GOTO, GOSUB, RETURN, REM, TAG,
    PROC, MODULE, LOCAL, GLOBAL, ADD, SUBTRACT, COMPARE, HALF, DOUBLE,
    VARIABLES, HALT, RESUME, VERSION, DEBUG, STARTINT, RASTER, BYTES and
    STRINGS.

START [*=] address                                         *visionbasic-START*
    Specifies the starting location for an ML program.

    Example: START *= 49152

    Must be placed at the very beginning of your ML program, and only used
    once.

    ML-safe: usable inside an ASSEM block.

SYS address[, A, X, Y, ST]                                   *visionbasic-SYS*
    Starts execution of ML code at address. If the A, X, Y and ST values are
    specified, they are loaded into the registers before starting.

    Example: SYS 49152, 0, 1, 2

EDITOR & COMPILER
------------------------------------------------------------------------------

AUTO                                                        *visionbasic-AUTO*
    Undocumented automatic line numbering.

    Present in the Vision BASIC token table but not documented in the cheat
    sheet.

COMP ["filename"[, devnum]]                                 *visionbasic-COMP*
    Compiles the program in memory and optionally saves the result to a file.

      filename (optional) string
        Output file name, 12 characters or less
      devnum (optional) integer
        Device to save to; the default device if omitted

    Example: COMP "MYPROG",8

CONT                                                        *visionbasic-CONT*
    Continues a stopped program.

    Present in the Vision BASIC token table but not documented in the cheat
    sheet.

DELETE [start-end]                                        *visionbasic-DELETE*
    Deletes the range of lines from start to end. With no parameters, acts
    like NEW.

    Example: DELETE 100-200

DESC line#, label                                           *visionbasic-DESC*
    Creates a subroutine label and starts its code at line#.

    Example: DESC 1000, DRAWSCREEN

ERROR                                                      *visionbasic-ERROR*
    Displays the errors.

EXEC command block                                          *visionbasic-EXEC*
    Runs a single line in immediate mode. Shorthand: >

    Example: > PRINT "HELLO"

    The > character is an accepted shorthand for EXEC.

FIND text                                                   *visionbasic-FIND*
    Searches the program in the current bank for lines containing text.

    Example: FIND [LDA

    Do not use quotes when searching for keywords. When searching for
    assembly, put a left bracket in front of the instruction.

HALT                                                        *visionbasic-HALT*
    Stops compilation at this point. All previous code will be compiled.

    ML-safe: usable inside an ASSEM block.

LIST [line#[-line#]]                                        *visionbasic-LIST*
    Displays the program in memory. Can optionally display only the lines
    between the given parameters.

    Example: LIST 100-200

LISTER [line#]                                            *visionbasic-LISTER*
    A scrollable LIST. If line# is specified, starts at that line.

    Example: LISTER 500

LITE [0/1]                                                  *visionbasic-LITE*
    With no parameter or a 1, enables LITE mode. 0 disables it.

    Example: LITE 1

LLIST [line#[-line#[, printer?]]]                          *visionbasic-LLIST*
    Displays extended details about the program in memory.

      line# (optional) integer
        First line, and optionally last line, to describe
      printer? (optional) 0-1
        1 sends the output to a printer

    Example: LLIST 100-200,1

MODULE filename[, devnum[, address]]  ...  MODULE END     *visionbasic-MODULE*
    When compiling, writes this section to a separate module file filename for
    reusability. MODULE END marks the end of the module.

      filename         string
        Module file to write
      devnum (optional) integer
        Device to write to; the default device if omitted
      address (optional) integer
        Load address; 49152 if not specified

    Example: MODULE "SPRITELIB",8,49152

    ML-safe: usable inside an ASSEM block.

MODULE END                                            *visionbasic-MODULE END*
    End of a module section.

NEW [bank[-bank]]                                            *visionbasic-NEW*
    Clears the current program bank, or the banks specified.

    Example: NEW 1-3

OLD [bank[-bank]]                                            *visionbasic-OLD*
    Attempts to restore the program in the current bank, or the banks
    specified.

    Example: OLD

PLIST [line#[-line#]]                                      *visionbasic-PLIST*
    Sends the program LIST to a printer.

    Example: PLIST 100-200

PREV                                                        *visionbasic-PREV*
    Undocumented.

    Present in the Vision BASIC token table but not documented in the cheat
    sheet.

QUIT                                                        *visionbasic-QUIT*
    Quits Vision BASIC.

RENUM start-end, new[, step]                               *visionbasic-RENUM*
    Renumbers the lines from start to end so that they begin at new.

      start-end        integer
        Range of existing lines to renumber
      new              integer
        New first line number
      step (optional)  integer
        Line number increment; 10 if not specified

    Example: RENUM 100-500, 1000, 10

RESUME                                                    *visionbasic-RESUME*
    Resumes compilation after a HALT.

    Must be at the beginning of a line, or it will be ignored.

    ML-safe: usable inside an ASSEM block.

RUN [line#]                                                  *visionbasic-RUN*
    Runs the compiled, in-memory program. If the program is not compiled or
    has been altered, compiles it first. If line# is specified, starts there,
    otherwise from the first line.

    Example: RUN

VLIST [num]                                                *visionbasic-VLIST*
    Displays all of the variables from the program in memory. If num is
    specified, sends the output to a printer.

    Example: VLIST

------------------------------------------------------------------------------
CONDITIONALS
------------------------------------------------------------------------------

ELSE statement                                              *visionbasic-ELSE*
    If the prior IF expression evaluated to FALSE, statement will be executed.

    Example: IF A = 1 THEN PRINT "ONE" : ELSE PRINT "OTHER"

IF expression [AND | OR | EOR expression]                     *visionbasic-IF*
    Evaluates the expression and sets a flag that will be acted upon when the
    program reaches a THEN statement.

    Example: IF A = 1 THEN PRINT "ONE"

THEN statement                                              *visionbasic-THEN*
    If the prior IF expression evaluated to TRUE, statement will be executed.

    Example: IF A = 1 THEN PRINT "ONE"

------------------------------------------------------------------------------
LOOPS
------------------------------------------------------------------------------

DO line#, times                                               *visionbasic-DO*
    Runs line line# times times.

    Example: DO 1000, 10

    DO loops only work on integer variables.

FOR var = start TO end [STEP val]                            *visionbasic-FOR*
    Defines a FOR loop that iterates variable var from start to end,
    incrementing by 1, or by val if STEP is given.

    Example: FOR I = 1 TO 10 : PRINT I : NEXT I

    FOR-TO-STEP-NEXT loops only work on integer variables.

NEXT var[, var[, ...]]                                      *visionbasic-NEXT*
    The end of the FOR loop. var must match the FOR loop you are continuing.

    Example: NEXT I

FOR var = start TO end STEP val                             *visionbasic-STEP*
    Sets the increment of a FOR loop.

FOR var = start TO end                                        *visionbasic-TO*
    Separates the start and end values of a FOR loop.

------------------------------------------------------------------------------
PROGRAM FLOW
------------------------------------------------------------------------------

END                                                          *visionbasic-END*
    Ends the execution of the program and returns the screen to normal.

GOSUB line#[, line#[, ...]]                                *visionbasic-GOSUB*
    Runs a subroutine at line#. If more than one line# is specified, runs each
    one in the order specified.

    Example: GOSUB 1000, 2000

    ML-safe: usable inside an ASSEM block.

GOTO tag | line number                                      *visionbasic-GOTO*
    Jumps to the line number or tag in the program.

    Example: GOTO 1000

    ML-safe: usable inside an ASSEM block.

ON var GOSUB | GOTO line#, line#, ...                         *visionbasic-ON*
    Jumps to the line# that matches the value of var.

    Example: ON A GOTO 1000, 2000, 3000

PASS vop[, vop[, vop[, ...]]]                               *visionbasic-PASS*
    Defines parameters vop for a subroutine. Must be the first command after
    PROC if you are passing parameters.

    Example: PASS X, Y

    Call a subroutine like tag.vop,vop,vop. Strings and string variables
    cannot be returned from subroutines.

POINT vop = line#   |   POINT TAG tag = line#              *visionbasic-POINT*
    Sets vop to the address of the compiled code for line line#. The POINT TAG
    form creates a tag and points it at that address instead.

    Example: POINT TAG ROUTINE = 1000

    Call a subroutine like tag.vop,vop,vop. Strings and string variables
    cannot be returned from subroutines.

PROC tag[, vop[, vop[, ...]]]                               *visionbasic-PROC*
    Defines the start of a subroutine named tag with parameters vop.

    Example: PROC DRAWBOX, X, Y

    Call a subroutine like tag.vop,vop,vop. Strings and string variables
    cannot be returned from subroutines.

    Note: Strings and string variables cannot be returned from subroutines.
    Call a named subroutine as `TAG.arg,arg`.

    ML-safe: usable inside an ASSEM block.

RETURN                                                    *visionbasic-RETURN*
    Ends a subroutine and sends program flow back to the GOSUB statement, or
    to the caller of a PROC.

    Call a subroutine like tag.vop,vop,vop. Strings and string variables
    cannot be returned from subroutines.

    ML-safe: usable inside an ASSEM block.

SEND vov                                                    *visionbasic-SEND*
    Makes the subroutine return the value vov. Must be the final command
    before RETURN if used.

    Example: SEND RESULT

    Call a subroutine like tag.vop,vop,vop. Strings and string variables
    cannot be returned from subroutines.

    Note: Strings and string variables cannot be returned from subroutines.

STOP                                                        *visionbasic-STOP*
    Stops the program execution but does not reset the screen.

TRAP line#[, vop]                                           *visionbasic-TRAP*
    Sends control of your program to line# on error.

      line#            integer
        Line to jump to when an error occurs
      vop (optional)   variable
        Non-arrayed int that will receive the address of the error

    Example: TRAP 9000, ERRADDR

TREND                                                      *visionbasic-TREND*
    Undocumented.

    Present in the Vision BASIC token table but not documented in the cheat
    sheet.

VARIABLES & TYPES
------------------------------------------------------------------------------

CLR                                                          *visionbasic-CLR*
    Clears the memory used by all variables.

DECIMAL variable[, variable[, variable[, ...]]]          *visionbasic-DECIMAL*
    Creates new decimal variables.

    Example: DECIMAL X, Y, RATE

    Variables must start with a letter and can be up to 8 characters long;
    anything past 8 characters is silently ignored. The symbols !, @, #, %, &
    and ? and numbers are allowed. Variable names can contain keywords but
    cannot start with one. Strings must be terminated with a dollar ($) sign.
    All variables are integers by default.

DEF type var[, var, var, ...]                                *visionbasic-DEF*
    Defines variable types in a structured fashion.

      type             TAG | LABEL | INT | INTEGER | DECIMAL
        The type to give the listed variables
      var              name
        One or more variable names

    Example: DEF DECIMAL X, Y

DIM [DECIMAL] variable(value)                                *visionbasic-DIM*
    Creates array variable of value size. DECIMAL makes it an array of
    decimals rather than integers.

    Example: DIM SCORES(20)

DUBL                                                        *visionbasic-DUBL*
    Double-precision variable type, used with DEF.

    Present in the Vision BASIC token table but not documented in the cheat
    sheet.

GLOBAL                                                    *visionbasic-GLOBAL*
    Restores the global variable scope.

    ML-safe: usable inside an ASSEM block.

INTEGER                                                  *visionbasic-INTEGER*
    Integer variable type, used with DEF.

    Example: DEF INTEGER X, Y

    Present in the Vision BASIC token table but not documented in the cheat
    sheet.

LET variable = value                                         *visionbasic-LET*
    Assigns a simple value to a simple variable. Useful for speed.

    Example: LET A = 5

LOCAL                                                      *visionbasic-LOCAL*
    Starts a local scope for variables.

    ML-safe: usable inside an ASSEM block.

SUB                                                          *visionbasic-SUB*
    Undocumented. Sits beside DUBL, LABEL and INTEGER in the DEF type group.

    Present in the Vision BASIC token table but not documented in the cheat
    sheet.

TAG tag [= vov]                                              *visionbasic-TAG*
    Creates a TAG named tag with the value vov. If vov is not specified, the
    tag gets the current address in the program. Used like a label in
    assembler.

    Example: TAG SCREEN = 1024

    Tags cannot be to the left of an equals sign in a math expression.

    ML-safe: usable inside an ASSEM block.

VARIABLES [address]                                    *visionbasic-VARIABLES*
    Moves the program variable table to address, or to 32768 if not specified.

    Example: VARIABLES 40960

    ML-safe: usable inside an ASSEM block.

DATA val, val, ...                                          *visionbasic-DATA*
    Holds data to be READ later.

    Example: DATA 1, 2, 3

DEBUG 0 | 1                                                *visionbasic-DEBUG*
    Enables (1) or disables (0) DEBUG mode, which reduces the number of passes
    for compilation. Results in slower and larger programs.

    Example: DEBUG 1

    ML-safe: usable inside an ASSEM block.

FAST                                                        *visionbasic-FAST*
    Enables speed up of some commands.

HALTINT                                                  *visionbasic-HALTINT*
    Stops the interrupt totally, returning interrupts to normal.

    It is critical to halt your interrupts before exiting your program.

    Note: Critical: always HALTINT before your program exits, or the machine
    is left running your raster interrupt.

INTEND flag                                               *visionbasic-INTEND*
    Should be the last statement in your interrupt routine.

      flag             0-1
        0 JMPs to BASIC's hardware timer routine, 1 will RTI

    Example: INTEND 1

    It is critical to halt your interrupts before exiting your program.

INTERRUPT raster, line#                                *visionbasic-INTERRUPT*
    Creates a new raster interrupt at raster line raster which calls the code
    at line#.

      raster           50-249
        Raster line to interrupt on
      line#            integer
        Line number of the interrupt routine

    Example: INTERRUPT 100, 5000

    It is critical to halt your interrupts before exiting your program.

    Note: Critical: always HALTINT before your program exits, or the machine
    is left running your raster interrupt.

PAUSE seconds[, jiffies]                                   *visionbasic-PAUSE*
    Pauses execution for seconds seconds. If jiffies is specified, pauses for
    an additional (jiffies/60) seconds.

    Example: PAUSE 1, 30

POINT TAG                                              *visionbasic-POINT TAG*
    Point a tag at the compiled address of a line.

RASTER raster                                             *visionbasic-RASTER*
    Selects the next raster line to interrupt.

    Example: RASTER 150

    It is critical to halt your interrupts before exiting your program.

    ML-safe: usable inside an ASSEM block.

READ vop, vop, ...                                          *visionbasic-READ*
    Reads values from a DATA statement.

    Example: READ A, B, C

REM                                                          *visionbasic-REM*
    Turns the rest of the line into a comment.

    Example: REM THIS IS A COMMENT

    ML-safe: usable inside an ASSEM block.

RESTORE [line#]                                          *visionbasic-RESTORE*
    Resets the pointer to the start of all DATA statements, or to the DATA
    statement on line line#.

    Example: RESTORE 1000

SLOW                                                        *visionbasic-SLOW*
    Runs at normal C64 speeds.

STARTINT                                                *visionbasic-STARTINT*
    Lets you program raster interrupts. Should be the first command in your
    interrupt routine.

    It is critical to halt your interrupts before exiting your program.

    Note: Critical: always HALTINT before your program exits, or the machine
    is left running your raster interrupt.

    ML-safe: usable inside an ASSEM block.

VERSION number                                           *visionbasic-VERSION*
    Specifies which version of Vision BASIC is needed to compile the block of
    code.

    Example: VERSION 1.1

    ML-safe: usable inside an ASSEM block.

WAIT address, and, eor                                      *visionbasic-WAIT*
    Waits for a non-0 result from PEEKing address and filtering it with AND
    and and EOR eor.

    Example: WAIT 53265, 128, 0
